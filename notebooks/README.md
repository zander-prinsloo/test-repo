# Notebooks

This folder contains Jupyter notebooks for exploratory data analysis and reporting.

## Naming Convention
Use a naming convention that indicates the order and purpose:
- `01_data_exploration.ipynb`
- `02_data_cleaning.ipynb`
- `03_feature_engineering.ipynb`
- `04_modeling.ipynb`
- `05_results_visualization.ipynb`

## Best Practices
- Keep notebooks focused on a single topic
- Document your analysis with markdown cells
- Clear outputs before committing to version control
- Move reusable code to the `src/` folder
- Use notebooks for exploration, not production code
